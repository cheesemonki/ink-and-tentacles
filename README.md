# 墨水与触手 · 深海牌局

解压后用浏览器打开 `index.html` 即可开始游戏。

## 卡面
图片铺满整张卡，底部渐变压暗显示名称与效果；不再标注流派/种类文字，只保留费用、名称、效果。
悬停时卡牌抬升放大，并在旁边浮出该卡涉及的关键词统一说明。战斗手牌共用同一个激活圆环，附加条件满足时圆心及卡边微亮。每张牌以物种命名，悬停名称可查看学名。未配置物种图的卡显示占位图。

## 图鉴
顶栏「📖 图鉴」或标题页入口，随时查看全部 360 张卡，可按流派 / 稀有度筛选。

## 智能发牌
每 3 张待选牌中，约 82% 概率保底出现 1 张你当前最厚流派的牌，双流派以上时第 2 槽位有 45% 概率偏向次厚流派；
其余按「流派权重 = 1 + 1.15×已选张数（上限 15 倍）」与「同名牌数量」加权抽取，牌库越集中越容易成流派。
新增流派无需改代码，权重按卡牌所属流派自动生效。

## 稀有度
普通 60% · 精良 26% · 稀有 11% · 传说 3%
稀有度只影响出现概率，与费用、洋流无关。
